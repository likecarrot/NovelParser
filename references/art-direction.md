# 整体美术方向与连载漫画参考

在通篇剧本阶段确定文字美术方向，冻结后才绘制基准和正文。目标是让全书具有统一、优雅、耐读的漫画语言，同时保留题材、人物和情绪的区别。

概念美术与人设设计师子代理负责具体的画风提案、参考画页解读、美术设计与构图规范制定；主代理作为总导演把控核心审美方向并做出最终定夺。画面与排版品控员子代理负责连续画页的逐页品控审阅。

## 选择适合本作的方向

用户给出画风、黑白/彩色或版式时优先沿用。没有指定时，以清晰的彩色叙事漫画、左至右阅读为起点，再依据全书调整。优雅主要来自线条、视觉层次和疏密关系；激烈动作、恐怖或粗犷人物仍应保留题材力度。

| 叙事需要 | 可采用的美术方法 |
|---|---|
| 抒情、旅行、日常、幻想 | 简洁人物线条、适度环境细节、柔和底色与明确明暗；远景和停顿画格承接情绪 |
| 悬疑、都市、人物交锋 | 清楚的黑白形块、局部强调色、稳定空间轴线；用视线、手部和反应镜头组织信息 |
| 动作、冒险、史诗 | 有主次的轮廓线、可读的剪影、明确动作方向；重点大格配短促反应格，特效集中在动作发生处 |
| 喜剧、轻松关系戏 | 清楚表情与肢体语言、简化非关键背景、轻快色彩；夸张尺度与回归常态的条件保持一致 |

这些是设计选项，选择符合原文的一种主方向并说明理由；不要每章重新挑选画风。

## 从连载漫画中提炼方法

优先使用用户指定的作品。否则可选少量题材相近的连载漫画官方预览，观察一段连续叙事；封面适合研究配色和造型，正文用于研究分镜和对白。以下入口供按需查看，观察方向是本技能的设计建议，不是官方风格定义或实时热度排名。

| 样本与官方入口 | 建议观察的维度 |
|---|---|
| [《葬送的芙莉莲》VIZ 第 1 卷预览](https://www.viz.com/manga-books/manga/frieren-beyond-journey-s-end-volume-1/product/6872) | 环境与人物的比例、静默镜头、景别切换、情绪停顿 |
| [《间谍过家家》VIZ 第 1 卷预览](https://www.viz.com/manga-books/manga/spy-x-family-volume-1-0/product/6302) | 表情可读性、对话场面的视线组织、动作与反应镜头、页面疏密 |
| [《全知读者视角》WEBTOON 第 1 话](https://www.webtoons.com/en/action/omniscient-reader/episode-1/viewer?title_no=2154&episode_no=2) | 纵向阅读、画格间停顿、重点镜头的占幅、色彩与光影的情绪作用 |

实际参考时记录在 style.references：作品、官方 URL、查看范围、访问状态、具体观察、适用于本作的规则。只有实际看到画页，才将 access 记为 viewed 并填写观察；若仅能读到介绍，记为 metadata_only；无法访问则记为 unavailable。访问受限时继续根据本作建立方向，不声称已经分析画页。

把参考转成可执行描述，例如“对话格用稳定中景和表情近景交替，转折处给整宽无字停顿格”。生成提示词以这些方法和本作基准为依据，避免只写“像某部热门漫画”；人物、服饰、构图和情节由本作重新设计。

## 记录并沿用美术规范

使用 style.art_direction。模板提供通用起点，依据原文和用户选择逐项调整，避免与 style.look/palette 互相矛盾。

| 字段 | 需要具体说明 |
|---|---|
| linework | 外轮廓与内细节的粗细关系、线条干净程度、纹理使用范围 |
| shape_language | 人物比例、轮廓和表情夸张尺度；与角色个体差异如何共存 |
| shading | 赛璐璐、柔和渐变、网点等主要明暗方法及混用条件 |
| color_rules | 主色、辅助色、局部强调色；肤色和角色识别色的稳定范围 |
| lighting | 常见光源、冷暖和对比规则；夜景、回忆等变化如何明确区分 |
| backgrounds | 建立空间时的细节、对话时的简化、前中后景的层次 |
| composition | 视觉中心、视线动线、负空间，以及脸、动作与文字区的优先级 |
| effects | 速度线、粒子、光晕和拟声字的使用场合与强度 |
| lettering | 正文、旁白、拟声的字号/层级、气泡形状和字色对比 |

默认可从少量协调主色与局部强调色开始，让高对比集中在人物表情、动作或关键道具；背景细节支撑场景而不抢视觉中心。黑白稿同样记录灰阶、黑块和网点规则。低饱和、浅背景或柔和光影只是选项，黑白或高反差画风也可以保持优雅。

回忆、梦境、夜景、喜剧夸张或能力发动可以有受控变化，说明适用场景与恢复条件。沿用身份、比例和核心线条语言，避免同一人物无依据地从写实切成另一套脸模。

## 分镜与页面节奏

编剧时就指定重点与停顿：建立环境的远景、交代动作的中景、落在表情或关键物的近景。每格有主要信息中心，视线与动作方向带读者进入下一格。背景复杂度随叙事用途变化，不把每格都写成同样密度的场景。

页面按阅读顺序组织。`page.rows` 可选，例如：

```json
{"id":"page-a","chapter_id":"实际章节ID","panel_ids":["p1","p2","p3"],"rows":[["p1"],["p2"],["p3"]]}
```

各 ID 必须来自真实分镜。页内格数由叙事节拍决定，不写画幅、字高或版面尺寸。

## 页面连续性检查

分镜锁定后，通读全卷检查：

- 同一场景跨页时，空间关系是否延续，人物是否突然换了位置；
- 人物的服装、伤势、持有物是否在相邻格之间无故变化；
- 情绪推进是否有过渡，还是从平静直接跳到崩溃；
- 每页的停顿位置是否落在叙事需要的地方。

发现漂移就修正受影响的分镜，并在 `state_before` / `state_after` 里体现真实变化。
